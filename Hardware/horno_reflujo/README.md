# 🔥 Custom Reflow Oven Hardware 🔥

This directory contains the main **KiCad project** for the custom reflow oven hardware.

---

## 📂 Files & Folders

- **horno_reflujo.kicad_pro**: The main KiCad project file.
- **horno_reflujo.kicad_sch**: The schematic file.
- **horno_reflujo.kicad_pcb**: The PCB layout file.
- **bom/**: Contains the Bill of Materials (BOM) for the project.
- **production/**: Contains the fabrication output files (Gerbers, drill files, etc.) for manufacturing the PCB.
- **horno_reflujo-backups/**: Automatic backups of the project files.

---

## 🚀 How to Use

1. **Open in KiCad**: Open the `horno_reflujo.kicad_pro` file in KiCad.
2. **View Schematic & PCB**: You can view and edit the schematic and PCB layout.
3. **Generate Fabrication Files**: Use the PCB editor to generate the fabrication files, which will be located in the `production/` directory.
