# 📊 Web Scraping & Data Analysis 📊

This directory contains Python scripts and other files for web scraping and data analysis related to the reflow oven project.

---

## 📂 Files

- **web_client.py**: A Python script that acts as a web client to interact with the oven's web interface. It can be used to automate testing and data logging.
- **fopdt.py**: A script for First-Order Plus Dead Time (FOPDT) modeling, used for analyzing the thermal dynamics of the oven.
- **regresion_horno.xlsx** and **regresion_horno2.xlsx**: Excel files containing data for regression analysis of the oven's temperature profiles.
- **horno_client.log**: A log file generated by the `web_client.py` script.

---

## 🚀 How to Use

1. **Install Dependencies**: Make sure you have Python 3 and any required libraries installed (e.g., `pandas`, `openpyxl`, `requests`).
2. **Run Scripts**: Use the Python scripts to perform data analysis or interact with the web client.
   ```bash
   python web_client.py
   ```
